# 学术写作

用于论文、学位论文、摘要、审稿回复和其他事实性研究材料。目标是表达清楚、论断可追踪、符合作者和学科的声音。基金申请还要读取 [基金与研究提案](grant-proposals.md)。

## 保真边界

- 数字、正负号、区间、单位、实验结果、统计量、p 值、变量、公式、图表编号、文献编号、作者年份、引用键及直接引语默认保持原样。
- 保留样本、数据集、时间、人群、条件、比较对象、失败结果、局限与例外。
- 不新增研究方法、数据、结果、来源、前期工作、合作关系、创新性或优先权。
- 保留“提示、相关、可能、在本研究范围内”等证据性限定，以及原文的否定和作者判断。
- 处理已有材料中的表达问题；外部文献调查、结果核查、重新计算和翻译术语需要相应任务范围，不由润色自动触发。

普通润色保持研究主张。用户要求校准论断、检查证据或审阅科学表达时，可以提出或实施与已有材料一致的调整，并明确报告实质变更；没有足够依据时，保留原句并在正文之外指出缺口。不能把自己未核实的怀疑写成新结论。

## 论断与证据

在证据审阅范围内，对经验性或比较性主张核对：

1. 原稿或用户材料中的哪个数字、图、表、检验、证明或引用支持它？
2. 是本研究结果、外部文献、作者前期工作，还是预期结果？
3. 动词、主语和范围是否超出了该证据？
4. 比较是否明确指标、对象、样本和条件？

| 材料给出的证据 | 应保留的边界 |
| --- | --- |
| 定理或形式化推导 | 成立条件、假设与结论范围 |
| 因果研究设计 | 被研究的处理、人群、条件和推断限制 |
| 基准或对照实验 | 实际任务、数据集、指标和基线 |
| 观察性或相关性结果 | 关联及已有不确定性，不升级为因果 |
| 个案、访谈与探索材料 | 该案例或材料中的观察，不推广成普遍机制 |
| 尚未完成的研究计划 | 假设、拟检验内容和预期结果，不写成已取得成果 |

只用已经提供的证据位置。材料没有图号、引用或数值时不补一个；仅有引用标记也不代表已经核实其支持关系。

## 防御性表达与必要限定

防御性表达包括反复否认未曾提出的更强主张、叠加同一层不确定性，以及为应付假想批评而添加的自我辩护。编辑目标是让已有主张和依据更清楚，同时保留会影响科学理解的条件、反证与局限。

### 先判断句子的作用

看删去或压缩后，读者对研究对象、证据、推理、适用范围或确定程度的理解是否会改变。按作用处理，不把“可能、仅、尚未、不能排除、虽然”等词当作禁词。

| 表达的作用 | 处理方式 |
| --- | --- |
| 交代真实样本限制、未验证范围、失败结果或方法约束 | 保留其信息及与主张的关系；表达生硬时可以改写 |
| 多个限定重复同一层不确定性 | 合并重复措辞；“可能相关”“只在单中心观察”“未做干预实验”是不同信息，不能一起压成一个“可能” |
| 反复否认作者未提出的全称、唯一性或必然性主张 | 已有主张准确限定范围、且没有额外澄清作用时，可删去重复辩护；真实概念区分和实际审稿质疑仍需回应 |
| 用“仅供参考、仍有不足”等笼统自我评价收尾 | 检查是否承载作者立场或具体边界；只重复已有内容时压缩，不替作者补写缺陷或把明确贡献改弱 |

### 让主张直接带上边界

优先把原稿已有的对象、条件、比较范围和确定程度写入主张，避免先留下宽泛判断，再靠后面的免责声明收窄。普通润色只调整表达，不能借此改变主张；需要重新确定科学范围或强度时，按论断校准的任务边界处理。

原文把机制写成“可能解释”时，保留这一关系，不先把它当成“已经证明唯一机制”，再补一段否认。原稿有依据的明确判断也不自动加“可能”“初步”或“仅供参考”。编辑者未核实某项证据，只能说明支持尚未核实，不能据此将作者结论写成不成立或没有支持。

不要自动添加“所有研究都有局限”“仍不能排除其他因素”等通用提醒。在证据审阅范围内，备选解释应针对可比条件下的同一现象，有材料依据，并可能改变当前解释、适用范围或结论；需要作者决定的解释放在正文之外。原稿已有的具体竞争解释、反证与未排除因素不能作为防御性措辞删除。

### 按论证需要安排限定

在同一阅读单元中，同一边界已经清楚表达、后文没有新增作用时，可以合并重复说明。会改变当前主张含义的条件应留在读者能直接对应的位置，不统一后移到局限章节，也不要求全文只能出现一次。

摘要、图注等需要独立阅读的部分应保留各自必要的限定。只提供局部段落时，不因猜测其他章节已经说明就删除边界；也不为每段凑齐“发现—不足—未来工作”。涉及跨段重排时，遵守用户要求的编辑深度和结构。

## 常见表达问题

### 过强动词与新颖性口号

“证明、首次、显著、彻底解决、填补空白、开创范式”需要检查含义和支撑。“显著”可能是统计术语，不能按宣传词删除；“首次”可能是作者明确的研究主张，普通润色不能静默改掉。

在允许证据校准的任务中，给出材料支持的较准确表达或指出需作者补证。不要把所有动词统一改成“提示”，也不把所有结论都加上“可能”。

### 空泛开场、贡献标签与意义拔高

删除不提供背景的“近年来受到广泛关注”等包装，保留真实研究背景、文献关系和问题。贡献列表应说明原稿已有的具体贡献；不能为了具体补造实验或优先权。

### 文献罗列与归因

可以按原稿已经说明的关系组织文献：一致、冲突、方法差异、适用条件或尚未解决的问题。没有全文或相关材料时，不从题目猜出观点，更不能添加不存在的引用。

### 长句、名词堆叠与过渡

可以拆开多层从句，保留因果、时间、同时发生、对比和前置条件。方法部分的被动和无主句有正常用途，不为主动语态虚构研究者身份。

同一专业术语保持一致。不要为了降低重复把变量、指标或理论概念轮换成含义不同的近义词。

## 按材料功能处理

- **结果：** 清楚陈述观察、数值和比较；讨论性解释不补进结果。
- **讨论：** 保留解释、证据来源、局限和推测程度，区分数据与解释。围绕实际证据讨论竞争解释，避免反复为假想的更强主张辩护。
- **摘要：** 保留用户或投稿模板要求的结构，以及独立阅读所需的研究范围和限定，不加入正文和材料未给出的结果。
- **结论：** 在提供的正文或作者材料基础上综合已建立的判断，保留相应范围与确定程度；不重新展开整套辩护，也不自动补泛泛的局限或未来工作。
- **方法：** 保留操作、参数、条件、顺序和可复现信息，不用“更简洁”删掉必要步骤。
- **审稿回复：** 保留审稿意见原文、编号、引用和改动状态；区分“已修改”“拟修改”“未采纳”。对实际质疑的解释、必要致歉和未采纳理由有回应作用，不能当作假想防御删掉。不要承诺未完成的分析，也不把回复中的改动叙述视为多余。

## 样本与声音

参考用户指定的既往论文、已录用稿或风格指南，匹配术语、句长、称谓、限定的位置和图表承接方式。不从样本移植成果和观点。没有样本时保留原稿学术语域，不强加第一人称、幽默或口语词。

## 示例

### 去掉空泛评价

**原文：** 表 3 显示，在三个数据集上，本方法的准确率分别比最强基线高 2.1、3.4 和 2.7 个百分点，配对检验的 p 值均小于 0.01。这些结果充分彰显了本研究的重大价值。

**可改：** 表 3 显示，在三个数据集上，本方法的准确率分别比最强基线高 2.1、3.4 和 2.7 个百分点，配对检验的 p 值均小于 0.01。

全部数值、单位、检验和比较对象来自原文；删除的只是没有独立信息的评价。不能改成“在所有任务上领先”或“准确率提升了 2.1%、3.4% 和 2.7%”。

### 合并重复免责，保留负结果

**原文：** 本方法的准确率高于基线（表 2），这一比较仅限于三个短文本数据集。我们并不声称本方法在所有任务中都优于其他方法。在长文本数据集 D 上，未观察到准确率提升。

**可改：** 在三个短文本数据集上，本方法的准确率高于基线（表 2）。在长文本数据集 D 上，未观察到准确率提升。

范围已经写进主张，泛化免责没有提供额外信息；长文本上的负结果仍须保留。不能把“未观察到提升”改成“已经证明无效”。若免责句回应实际误解或期刊要求，则保留其澄清作用。

### 合并同一层不确定性，保留不同边界

**原文：** 这些变化可能也许与机制 X 有关；样本仅来自单中心，尚未开展干预实验。

**可改：** 这些变化可能与机制 X 有关；样本仅来自单中心，尚未开展干预实验。

只合并“可能也许”。单中心范围和未开展干预实验各有含义，不能随限定词一起删掉，也不补新的机制或原因。

## 交付与核对

默认给终稿。学术审阅涉及实质论断调整时，简短列出调整及依据；材料缺口列为“需作者处理”。用户只要终稿时，不额外附流程报告或自评分。

逐项对照数字、公式、结果、引用和限制后，再按实际核对范围说明保真情况；不能把声明“全部保持不变”当作已经完成检查。未提供正文或证据时，不声称验证了论断。

删除或合并前，确认原句承担的研究问题、推理步骤、证据支持或边界在改稿中仍有着落；没有其他文字承接时，保留并改写。改后连读受影响的段落，核对“上述结果”“因此”等指代与逻辑，以及引用、图表和公式的引入关系。只有发现具体的跨段依赖时才扩展阅读，读取关联处不等于获得修改授权。

最后同时核对：科学含义和主张强度是否保持，重复防御是否减少、论证是否仍然清楚。保留必要限定可以是正确结果，不以删除数量、语气更强或字数减少作为通过标准。
