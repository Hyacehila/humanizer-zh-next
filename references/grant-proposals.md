# 基金与研究提案

用于已有基金申请、研究计划与项目提案的润色和论证审阅。研究结果、公式和引用的保护同时遵守 [学术写作](academic-writing.md)。

## 原稿与模板

先使用用户提供或明确指定的当年度、当项目模板，保留栏目、标题、字数、页数和附件要求。没有模板不妨碍一般文字润色，但不能声称已经满足申报要求。

任务需要核对现行模板或申报规则时，查阅对应资助机构的官方材料；记录适用年度和项目类型。不要根据往年的国自然、NSF、NIH 或其他项目要求推断当前约束，也不把一种机构的栏目强加给另一种申请。

## 论证关系

在用户要求论证审阅或深入修改时检查：

| 关系 | 要看什么 |
| --- | --- |
| 已知事实 → 科学问题 | 具体缺口、矛盾或未解释现象是什么 |
| 科学问题 → 研究目标 | 目标是否回答问题，边界是否清楚 |
| 目标 → 研究内容 | 各项内容承担什么作用，是否遗漏或重复 |
| 内容 → 方法与验证 | 方法为什么能回答问题，结果怎样判断 |
| 前期基础 → 可行性 | 哪项已有工作或条件支持哪个环节 |
| 风险 → 替代路径 | 关键假设失败时，哪些后续工作仍可完成 |
| 预期结果 → 科学价值 | 可能形成何种认识、方法或工具，适用范围是什么 |

这些关系不要求分别成为标题，也不要求固定数量的研究目标。用户只要求轻润色时，保留原结构，把论证问题作为可选建议放在正文之外。

## 常见缺口

- 只写“意义重大”而没有具体问题及后果。
- 把“采用深度学习”等方法当作研究目标。
- 立项依据的问题与后文内容、方法和验证互不对应。
- 后续目标完全依赖前一项成功，原稿却没有说明风险和替代路线。
- “首次、国际领先、颠覆性”等判断没有具体比较依据。
- 研究基础是无关履历列表，没有说明如何支持当前计划。
- 不同栏目重复同一段话，没有承担各自的信息功能。

这些缺口由作者补材料或调整计划。不能为增强说服力编造论文、实验、合作、设备、团队能力、成果或预期效果，也不把编辑者提出的替代方法写成原有承诺。

## 保留合理愿景

申请书说明尚未完成的研究。原稿有科学问题、路径和基础支撑的愿景可以保留；不能套用论文去宣传规则把长期目标全部删除。

区分“拟检验”“计划验证”“预期形成”和“已经证明”。前期单中心或小样本结果不能升级为已完成的多中心验证；设备和合作尚待落实时不改成已经具备。

## 示例

**原文：** 不同数据源如何影响预测误差，目前尚不清楚。申请人已在单中心数据上完成原型验证，结果见图 1。本项目拟分析不同数据源对预测误差的影响，并在两个独立队列中检验模型稳定性，为解决这一问题作出开创性贡献。

**可改：** 不同数据源如何影响预测误差，目前尚不清楚。申请人已在单中心数据上完成原型验证，结果见图 1。本项目拟分析不同数据源对预测误差的影响，并在两个独立队列中检验模型稳定性。

保留问题、前期结果、图号、两项计划和队列数量。不能补“已经建立多中心平台”，也不把“数据来源影响误差”改成已确认的因果机制。

## 输出

一般润色给终稿。论证审阅可以简短指出对应关系、材料缺口和需要作者决定的调整；不显示机械的评分面板。

只有实际核对过所给模板，才说明符合哪些具体栏目或格式要求。技能不替代申报机构要求，也不处理作者没有要求的申请提交、承诺或披露。

承接本项目远端 1.3.0 的中国基金申请模式，并参考 AIScientists-Dev/academic-humanizer 的目标与可行性审阅。年度规则改为按任务核对，避免固定模板过期。固定版本与取舍见维护文档 [上游整合记录](../docs/upstream-sources.md)，编辑任务不需要额外加载。
